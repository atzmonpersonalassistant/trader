# Output

Runtime outputs generated by scanner runs.

Typical files:

- `options-radar.csv` — latest tabular options radar output.
- `options-radar.json` — latest JSON options radar output.
- `market_radar_state.json` — RSS deduplication state for Market Radar.
- `*_cron.log` — scheduler/wrapper logs when enabled.

These files are runtime artifacts, not source-of-truth strategy logic. Keep only small examples if useful; do not rely on them as durable research records.
